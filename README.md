# 📊 Inventario

Sistema de control de productos, stock, movimientos y valor estimado del inventario.

## Gestión
- Agregar, editar y eliminar productos.
- Definir precio y cantidad disponible.
- Crear categorías.
- Registrar entradas y salidas de mercadería.
- Buscar y filtrar productos.
- Ver productos con poco stock y productos agotados.
- Actualizar cantidades y consultar movimientos.

## Dashboard
- Productos totales.
- Productos disponibles.
- Productos con poco stock.
- Productos agotados.
- Valor aproximado del inventario.
- Entradas y salidas.
